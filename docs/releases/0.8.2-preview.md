# Android 0.8.2 preview — conversation context

## Changes

- Explicit follow-ups such as “why is that?”, “explain it simply”, and “give me an example” reuse the most recent source-backed topic. The current question's emergency/medication boundary runs first. A greeting, unrelated unsupported topic, clarification, or safety-boundary reply breaks the topic chain.
- Follow-ups without a previous source-backed topic ask which topic the user means. Broad requests such as “help me” and “where do I start” ask for a topic instead of guessing.
- Welcome, clarification, and unsupported-topic replies offer Sleep, Nutrition, Hydration, Food safety, and Movement buttons. Buttons fill an editable draft without sending it; replacing an existing draft requires confirmation.
- The optional recent-context switch now supplies up to three previous source-backed exchanges as bounded JSON: question text capped at 240 characters and complete source summaries capped at 450 combined title/body characters per exchange. Summaries that do not fit are omitted and marked. Prior AI replies, journal data, and urgent/medication-boundary exchanges are excluded.
- The local AI prompt instructs the model to use recent exchanges for conversational references and current source summaries as evidence, and acknowledge missing examples/details.

## Privacy and scope

Recent-exchange sharing stays off by default and resets on activity recreation. Saved-profile sharing has its separate existing opt-in. Chat remains in the session and is cleared by Clear; there is no new disk storage or network access.

Follow-up recognition uses a bounded list of explicit English phrases. This is not general conversational understanding, multilingual symptom assessment, or proof that model outputs are accurate. The bundled information library remains small; repeating its summaries does not add new information.

## Build status

Android debug builds are compiled for this preview. No new automated tests, physical-phone checks, or conversation runtime validation were performed for these changes. The 0.8.1 starter-model compatibility fix is retained; its emulator evidence is documented separately.
