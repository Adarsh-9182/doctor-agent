# Android 0.8.3 preview — interface polish

## Changes

- Added brief ease-out fade-and-rise transitions when switching pages, and when chat replies appear. Animations honor the device animator setting.
- Added a subtle pressed scale on buttons and a small lift on the selected navigation tab.
- Added light borders, small elevations and consistent rounded corners to cards and the chat composer.
- Refreshed the app subtitle and updated the displayed version from the build configuration.

The app remains a native offline Android UI. Animations are short and do not run model work. The Android debug build compiled and the Home screen was visually inspected in the API 37 emulator. Physical-device appearance, other screens, and accessibility scaling were not checked for this preview.
