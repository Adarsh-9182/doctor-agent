# Doctor Agent Android 0.8.8 preview

This Android preview expands the companion beyond daily wellbeing into broader health education and clinician-visit preparation. It remains a bounded prototype, not a clinically validated doctor.

## What changed

- Home and Chat entry points for symptoms, lab reports, medicines, mental health and conditions.
- New Care tab: six optional structured fields for a visit, with a required main concern. Review exact user-entered notes before adding them to Chat. Blank fields remain “Not entered”; no model invents missing details.
- General clinician questions accompany reviewed notes. Source citations remain available.
- Care forms stay in memory across navigation and rotation; closing the process loses the draft. They are not written to disk or automatically supplied to the model. Adding to Chat and saving a chat are separate explicit actions. Clearing a form does not delete chat copies.
- Fourteen source summaries, with English, Romanized Hindi and Devanagari versions. Eight new topics cover visits, lab results, medicines, mental health, diabetes, blood pressure, vaccines and pain.
- Existing urgent-language and medication-request boundaries run before topic retrieval. Care review also checks urgent language; this limited phrase check cannot determine that a concern is safe.

## Builds

- Standard debug APK: source answers; optionally import a compatible model.
- With-model debug APK: includes the pinned Qwen3 0.6B starter. In You, explicitly enable local AI drafts. Model responses remain unverified.
- SHA256SUMS file for both APKs.

## Checks and limits

The Android Java retrieval/safety engine passes 67/67 synthetic development cases, including the new topics, selected Hindi routing, and emergency/dose precedence. Results: `evals/results/android-0.8.8.json`. Reproduce with `python3 scripts/evaluate_android.py`. These are development cases, not held-out clinical evaluation or a GPT comparison. Both Android APK variants compile. Device UI, rotation, local-model quality, and clinical correctness have not been verified for this version.

The Care UI is currently Android-only. The shared catalog also supplies the desktop source library, but desktop does not yet have this Care workspace. PDF/photo uploads, individualized lab interpretation, interaction checking, diagnosis, prescribing and autonomous clinical decisions are not implemented. The 14 summaries do not provide comprehensive medical coverage. No account or paid API is required; Android has no internet permission.
