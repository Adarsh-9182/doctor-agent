# Android 0.8.5 preview — health-first conversation UI

## Changes

- Reworked the chat surface around a source-led health learning companion, with visible topic starters and a compact source/AI status banner.
- Added distinct, right-aligned user bubbles and agent messages with a small companion mark, clearer labels, spacing, and subtle entrance motion. Motion respects Android's disabled animation setting.
- Added an updated composer and concise wellbeing-topic suggestions. Tapping a suggestion fills an editable draft; it does not send automatically.
- Updated Home topic cards to use the same review-before-send flow.
- Existing source library, AI draft controls, voice input, and safety boundaries remain the available capabilities. This release does not add broad medical knowledge or clinical assessment.

## Validation limits

The Android debug APK compiled. No automated tests, emulator or physical-phone UI review, accessibility review, or user research was performed for this release. Animation and layout may vary across Android versions, display sizes, font scaling, and keyboard modes. AI drafts are not medically validated; the bundled source library remains limited to its documented topics.
