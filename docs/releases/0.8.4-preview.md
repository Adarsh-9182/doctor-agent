# Android 0.8.4 preview — Hindi and Hinglish coverage

## Changes

- Added curated Hindi summaries in Romanized Hindi and Devanagari for the six bundled source topics, with source-matched topic words in Hindi/Hinglish.
- Added bounded Hindi/Hinglish emergency and medicine-intent phrases. The existing English checks still run; localized self-harm/emergency messages use India 112 and Tele-MANAS 14416 only when the device locale is India.
- Added English/Hinglish/Devanagari recognition for supported output language, Hindi follow-up and clarification phrases, and topic suggestions in Romanized Hindi or Devanagari to match the prompt.
- The local model is asked to reply in the language and script of the current question. A basic additional output check blocks some obvious Hindi/Hinglish medication instructions. This does not make the model clinically safe. Offline voice recognition remains English-only.
- Requests for topics outside the bundled source library still receive a clear unsupported-topic response.

## Source basis

Hindi source summaries are concise translations of this app's existing cited source summaries; the original references still open their official source pages.

- [MedlinePlus: Nutrition](https://medlineplus.gov/nutrition.html)
- [MedlinePlus: Sleep Disorders](https://medlineplus.gov/sleepdisorders.html)
- [MedlinePlus: Water in diet](https://medlineplus.gov/ency/article/002471.htm)
- [CDC: Preventing Food Poisoning](https://www.cdc.gov/food-safety/prevention/)
- [MedlinePlus: Exercise and physical fitness](https://medlineplus.gov/exerciseandphysicalfitness.html)
- [India ERSS: emergency number 112](https://112.gov.in/)
- [India DGHS: Tele-MANAS](https://www.dghs.mohfw.gov.in/national-mental-health-programme.php)
- [CDC: stroke warning signs](https://www.cdc.gov/stroke/signs-symptoms/index.html)

## Validation limits

The Android debug build is compiled. No automated tests, phrase-level safety checks, fluent-Hindi review, external clinical review, physical-phone checks, or model-runtime evaluation in Hindi were performed for this preview. The keyword lists cover selected phrases and spelling variants; they can miss emergencies or misread ordinary questions. Emergency guidance is not a substitute for local services.
