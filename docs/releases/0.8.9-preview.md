# Doctor Agent 0.8.9 preview — chat redesign

## Android

- Chat opens first, with a distinct lavender palette, rounded controls and a shorter welcome.
- Hamburger navigation opens an animated side panel: Chat, Home, Care, Library, You and directly accessible saved chats. Manage history retains rename/delete controls. Back closes the drawer before leaving Chat.
- Saved chats still use encrypted, explicitly saved snapshots; the drawer does not introduce automatic saving.
- Composer groups the typed draft, on-device Voice, Save/Update, Send and a Stop control while local AI is busy.
- Answer tools are arranged together. Sources and bundled summaries expand on demand, while response text and safety labels remain visible.
- Page/message/drawer animations and button motion respect Android's animator setting. Navigation can scroll on short screens.

## Native Mac

- Native split-view sidebar with health topics, session chats, source library and local-Ollama switch.
- Keep chat stores up to 20 in-memory snapshots, with up to 80 messages per conversation. Closing the app clears them. New/open-chat confirmations protect the current conversation and draft.
- Stop response cancels the active task and rejects stale responses. Copy, Listen and Stop reading actions, expandable source links and a larger composer.
- Native appearance follows system colors; animated scroll respects Reduce Motion.

## Local web and installable web app

- Local web app has responsive sidebar navigation, light/dark theme, starter cards, rounded composer, Copy/read/stop tools and expandable source summaries.
- Local web session chats are explicitly kept in RAM, capped at 20 snapshots/80 messages. Reload clears all snapshots and theme choice. Keep chat updates the current copy; remove deletes the session copy only.
- Stop response aborts the browser request and ignores stale replies. It does not guarantee the server or Ollama stops computation.
- Topic cards fill a draft; Send remains explicit. Mobile drawer supports Escape, keyboard focus trapping and a backdrop, with the page inert while open.
- The web welcome icon, cards, message entry and hover effects respect prefers-reduced-motion.
- Installable web app receives matching lavender styling, message animation and general-health topic drafts. It does not receive the local-server sidebar or session history implementation.

## Downloads and scope

Standard Android debug APK, Android APK with the pinned free starter model, a universal macOS app ZIP (macOS 14+, Apple Silicon and Intel), an installable web-app ZIP, and checksums.

Both Android APKs and the universal Mac app compile. The native Mac accessibility view was inspected after launch. No automated test suite was run for this UI iteration. Android device layout, browser rendering, session switching and model behavior have not been verified end to end. Browser visual preview was unavailable during this session.

This updates the interaction design; it does not implement ChatGPT feature parity, streaming model tokens, attachment/report upload, personal result interpretation or diagnosis. Source summaries and local AI drafts remain limited and clinically unvalidated. Android Care remains available from the sidebar; Mac and web do not yet have the structured Care form.
