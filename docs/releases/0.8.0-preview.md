## Android companion preview

This is a debug-signed development preview, not a clinically validated medical product. Both APKs compile successfully. No physical phone was connected during this build, so device execution, model performance, voice, widgets and reminder delivery remain unverified. Product testing was deferred at the user's request.

### Choose an APK

- **Doctor-Agent-android-0.8.0-with-model-debug.apk (~550 MB):** Qwen3 0.6B mixed-INT4 is included. No separate model import is needed. Open **You**, enable local AI drafts, then ask a general covered topic in **Chat**. The first generation creates a private model copy; allow additional free storage and several GB of available RAM for CPU inference. Phone compatibility is not guaranteed.
- **Doctor-Agent-android-0.8.0-debug.apk (~52 MB):** source answers, journal, reminders and companion controls without bundled weights. A compatible model can be imported separately.

Both builds target supported 64-bit Android 8.0+ devices. On-device dictation additionally requires Android 12+, a compatible service and an installed offline English language pack. Installing the same package updates the previous app without intentionally clearing its data. Android may require allowing installation from the downloading browser or file app.

### What's included

- Home-screen widget with one-tap Chat and Check-in access.
- Optional encrypted name and habit-goal memory, with a separate AI-sharing choice.
- Encrypted daily journal kept outside AI context.
- Source-linked general health information and limited topic continuity.
- Optional local AI drafts; source answers remain available on model failure.
- Optional on-device voice drafts, reviewed before sending.
- Optional local daily reminders with notification controls; Android can delay them.

No continuous microphone listening, background inference, account, cloud push or app internet permission. The model is a general language model, not health-fine-tuned. The app cannot diagnose or prescribe and does not replace professional care. The included weights use Apache 2.0; the pinned revision/checksum are in `models/starter-model.json`, and model/runtime licenses are bundled in the app.

`SHA256SUMS-android-0.8.0.txt` contains the APK checksums. Mac and PWA builds are not updated by this release. No NutritiScan website changes are included.
